# Cothon

A quiet, local-first personal assistant for Windows. A single C# core process, Avalonia UI, MCP tools, Gemini Live behind a provider adapter. Built for daily use, not distribution.

## Principles
- Quiet instrument, not a HUD
- One core language
- Tool contract is the product (JSON Schema + risk + reversible + preview + undo)
- Verify, never assume success
- Path confinement, capability scopes, audit trail
- Typed IPC/JSON-RPC, no declaration drift
